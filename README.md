# Greenhouse ledger

온실과 식물을 직접 등록하고, 배치의 수량과 생장 단계를 보는 화면입니다. 데이터는 [greenhouse-ledger-backend](https://github.com/ljs3536/greenhouse-ledger-backend)에 저장됩니다.

온실 수와 식물 종류는 고정되어 있지 않습니다. 다른 식물을 들이면 식물 메뉴에 추가합니다.

메뉴는 네 개입니다.

- 모니터링에서는 전체 포트, 출하 가능 수량, 온실별·식물별 현황을 봅니다.
- 배치에서는 목록을 보고, 심은 날과 현재 단계, 포트 수를 등록합니다. 단계 변경과 입고, 폐기, 판매도 여기서 기록합니다.
- 온실에서는 동을 추가하거나 삭제합니다.
- 식물에서는 관리할 식물을 추가하거나 삭제합니다.

## 기술

- Next.js 16
- React 19

`/api`로 보내는 요청은 `next.config.ts`에서 http://127.0.0.1:8080 으로 전달됩니다.

## 실행

백엔드와 MariaDB를 먼저 켠 다음 이 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

화면은 http://127.0.0.1:3000 입니다. Node.js 20 이상이 필요합니다.

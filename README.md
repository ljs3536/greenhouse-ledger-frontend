# 네 동의 장부

심비디움, 호접란, 덴파레, 온시디움을 동마다 몇 포트 키우고 있는지 적는 화면입니다. 데이터는 [greenhouse-ledger-backend](https://github.com/ljs3536/greenhouse-ledger-backend)에 저장됩니다.

이 화면에서 할 수 있는 일은 네 가지입니다.

- 지금 키우는 포트를 배치로 등록합니다. 심은 날, 현재 단계, 포트 수를 남깁니다.
- 단계를 육묘, 생장, 꽃대, 개화, 출하 가능으로 바꿉니다.
- 입고, 폐기, 판매를 날짜와 함께 기록합니다. 판매는 출하 가능 단계에서만 됩니다.
- 동별 전체 수량과 지금 팔 수 있는 수량을 봅니다.

## 기술

- Next.js 16
- React 19

`/api`로 보내는 요청은 `next.config.ts`에서 http://127.0.0.1:8080 으로 전달됩니다.

## 실행

백엔드와 MariaDB를 먼저 켠 다음 이 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

화면은 http://127.0.0.1:3000 입니다. Node.js 20 이상이 필요합니다.
